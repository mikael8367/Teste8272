# InicialApp

Aplicativo Android simples com um botão **Inicial**.

## Gerar o APK

1. Abra a aba **Actions** no GitHub.
2. Selecione **Build APK**.
3. Clique em **Run workflow** ou faça um push na branch `main`.
4. Quando terminar, abra a execução e baixe o artefato **InicialApp-debug**.

O APK gerado é `app-debug.apk`.
